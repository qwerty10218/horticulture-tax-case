# 研究計畫書

> 詳見 [專案索引](../README.md)

## 研究目標
透過「大葉園藝有限公司」一個虛擬案例，讓剛學完基礎會計的學生，能完整走過公司設立與一整年稅務申報的實務。

## 案例設定

| 項目 | 設定 |
|---|---|
| 公司名稱 | 大葉園藝有限公司（虛擬） |
| 負責人 | 陳大葉（家族第二代） |
| 股東 | 陳父 50%、陳大葉 50% |
| 資本額 | NT$100 萬元 |
| 登記地址 | 自宅（直系親屬房產） |
| 設立年月 | 2026 年 2 月 |
| 會計年度 | 曆年制 1/1～12/31 |
| 主要業務 | 綠化服務（代號 813000，應稅為主線） |
| 次要業務 | 網路銷售、園藝維護服務 |
